JavaScript - Fetch.

Fetch es una función de JavaScript que permite realizar solicitudes HTTP para obtener recursos de un servidor o enviarle información. Se utiliza, por ejemplo, para consultar API, recuperar archivos JSON y comunicarse con servicios web.

A diferencia de una asignación común, la información solicitada no está necesariamente disponible de inmediato. JavaScript debe esperar a que se complete la operación para poder trabajar con la respuesta.

Sintaxis básica. 
    fetch("https://ejemplo.com/datos.json")
        .then(respuesta => respueta.json())
        .then(datos =>{
            console.log(datos)   
        });

En este ejemplo se realiza una solicitud a una dirección web, se interpreta la respuesta como JSON y finalmente se muestran los datos obtenidos.

¿Cómo funciona fetch()

El proceso se puede divir en tres etapas:

  1. Realizar la solicitud.

        fetch ("https://ejemplo.com/datos.json")

    Se inicia una solicitud al servidor utilizando la dirección indicada.


  2. Procesar la respuesta.

        .then(respuesta => respuesta. json())

    Se recibe un objeto response y se utiliza su método json() para interpretar el contenido de la respuesta.


  3. Utilizar los datos

         .then (datos =>{
        console.log(datos);
    });

    El parámetro datos recibe el resultado de la conversión y permite trabajar con la información obtenida.


¿Qué es una promesa?

Una Promise (promesa) es un objeto de JavaScript que representa el resultado futuro de una operación que puede completarse correctamente o fallar.

fetch() devuelve una promesa por que la solicitud requiere tiempo y depende de la comunicación con el servidor.

Una promesa puede encontrarse en tres estados:

  • Pendiente: La operación todavía no terminó.

  • Cumplida: La operación se completó correctamente.

  • Rechazada: La operación falló.

Para trabajar con el resultado de una promesa se puede utilizar el método .then().

El método .then().

Permite indicar una función que se ejecutará cuando la promesa anterior se cumpla. Esa función puede recibir como parámetro el resultado de la operación. 

    .then(resultado => { 
        console.log(resultado);
    });

En este ejemplo, resultado es un parámetro de la función flecha. Recibe el valor que entrega la promesa anterior.

El nombre del parámetro puede cambiarse sin modificar el funcionamiento. 

    .then(datos => { 
        console.log(datos);
    });

En ambos casos, el parámetro recibe el resultado correspondiente. El nombre elegido sirve para identificarlo dentro de la función.


¿Qué es respuesta.json()?

Cuando se utiliza fetch(), el primer resultado es un objeto Response, que representa la respuesta HTTP del servidor. Este objeto no es directamente el conjunto de datos que queremos utilizar.

Si el servidor devuelve contenido JSON, podemos utilizar el método .json() 

     respuesta.json()

Este método lee el cuerpo de la respuesta e interpreta su contenido como JSON. El resultado es otra promesa, que al cumplirse entrega el valor convertido a JavaScript.

Por ejemplo, si el servidor devuelve este JSON: 

    {
        "nombre": "Ana",
        "edad": 17
    }

podemos acceder a los datos obtenidos: 

    .then(datos => { 
        console.log(datos.nombre);
        console.log(datos.edad);
    });

En este caso, datos es el parámetro que recibe el objeto convertido, nombre y edad son propiedades de ese objeto.

Acceder a las propiedades de un objeto

Una vez que los datos se encuentran disponibles en JavaScript, podemos acceder a sus propiedades utilizando la notación de punto. 

    console.log(datos.nombre);
    console.log(datos. edad);
